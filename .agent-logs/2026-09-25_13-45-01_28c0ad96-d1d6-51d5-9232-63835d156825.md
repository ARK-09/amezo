## Three bugs found along the way

**The shadcn components had a systemic styling bug.** They style state with Tailwind's bare `data-open:` / `data-active:` / `data-horizontal:` variants, which compile to attribute-presence selectors (`[data-open]`). Radix emits `data-state="open"` and `data-orientation="horizontal"` — so none of it matched. Dialogs and sheets had no transition, and the selected tab looked like every other tab. Eight components affected. I confirmed this against the compiled CSS rather than reasoning about it, and changed only the variant selectors. Same root cause as the checkbox/radio/switch fix earlier. **Worth knowing if you regenerate them.**

**Demo mode was unreachable.** `SellerAuthContext`'s boot check opts out via `DEMO_AUTH`, but its `api:unauthorized` listener didn't — so the 401 that `/sessions/current` returns for a visitor signed the demo seller straight back out. Pre-existing on main; found because I couldn't screenshot the portal.

**A query-key namespace bug of my own** — the v1 lists were keyed separately from the existing hooks, so deleting a product left it on screen. The v1 keys now nest under `['seller','products']` and `['seller','orders']`.
